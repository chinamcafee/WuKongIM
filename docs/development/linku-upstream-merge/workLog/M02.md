# M02：运行时与业务兼容合并

执行日期：2026-10-04 至 2026-10-05。

## 保留与合并

- 保留签名设备凭据、版本 CAS、轮换/接管区分、设备级 CMD 游标、好友发送鉴权、WKProto v6 失败 CONNACK，以及业务接口和准备指令静默规则。无签名历史 CMD HTTP 入口继续返回 404；上游绑定/解绑与 UID CMD 目录在其内部端口继续工作。
- 使用上游分页成员目录、权威会话 head、消息更新、MQTT、备份/迁移和工具实现；接入链卿精确 red-dot 未读规则。自发消息不清未读，SyncOnce 不计普通未读。跨节点扫描读取 Channel 权威节点原始已提交消息，避免 ingress 副本或编辑后 payload 改变计数和分页。
- 保留链卿历史 Conversation 表 6、设备 CMD 表 16 和凭据 FSM 52/53；上游 UID CMD 使用表 29，普通会话 read/hide 使用 FSM 200/201。恢复旧数据读取兼容，版本化凭据不可被通用旧 Token 写入降级覆盖；迁移验证明确校验旧格式对应的原生新增字段为零。
- 保留 Channel Expire TLV 8，上游 SendBan 改用 10；支持历史及组合 Channel value 编码。Channel RPC 13/14 同时携带业务 Topic、投递元数据和路由围栏；匹配版本的集群节点须一起部署。新设备游标 RPC 200 按 UID 路由到当前 Slot leader，并限制批次和 wire 大小。
- 同时保留 Channel 全局 client_msg_no 幂等和上游历史查询、Will 去重索引。只有同发送者、同正文的并发幂等消息可合并，冲突发送仍逐个验证；Topic、Expire、RedDot、SyncOnce 不在转换中丢失。
- SyncOnce 持久成功后写入设备 CMD 投影，投递关闭仍可同步；投影失败不改写已持久 SENDACK。原生绑定/tombstone 优先于历史投影，不复活已解绑频道。
- 保留持久 Webhook outbox、稳定事件 ID、重试/死信/崩溃重放及按设备推送资格。合并可选通知批次，默认单条兼容；批次重组仍以原单项 event_id 去重。离线事件保持 msg.offline.v2 和设备目标合同。
- 修正 MQTT source-drain 取消期间父 context 传播的竞态：订阅域已取消时不误报 pending；保留未确认状态和取消错误。
