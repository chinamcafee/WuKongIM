本轮完成了用户确认的 **1001→1、1002→2、1003→3** 配置分配，并使用真实
备份的三份配置和同一份旧插件程序，通过了隔离环境中的启动、单聊和群聊
回复测试。尚未完成用户绑定的正式导入与独立验证，没有执行现场迁移或切换。

## 实现范围

迁移计划新增 `plugin_nodes`。准备流程检查完整的一一对应关系；不能遗漏节点、
重复使用节点或把多份配置合并到一个目标。节点顺序不决定映射，显式映射决定。
不指定该字段时保持原流程；指定它也不会解除插件业务兼容检查。

从捕获的原始 Plugin 行解码并保留注册字段，配置和模板保持原字节。原版状态
0/1 映射为启用，2 映射为禁用；时间戳保留纳秒。分配记录携带源节点、目标节点、
原行位置和摘要、原注册信息及 v3 原生 DesiredState。报告只输出计数和摘要。
消费分配记录前先检查全部记录摘要，输出被修改时在调用消费者前拒绝。

PrepareArchive 从原归档行重新计算配置分配；不会信任旧的分配产物。当前这些
记录是供后续完整插件导入使用的配置阶段结果，没有安装可执行程序，也没有
把它们当作业务兼容或 PREPARED 成功的替代证据。
