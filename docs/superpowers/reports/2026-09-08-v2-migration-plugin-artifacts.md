# 原插件程序归档、安装与限定兼容规则

日期：2026-09-08；工作树：codex/v2-v3-migration。

工具已将原程序捕获、可移植归档重建、目标安装和独立文件校验接入生产迁移命令。
兼容规则只覆盖已审计的具体 AI 示例程序，不接受任意“compatible=true”声明。
recovery-48 已对完整真实源通过该规则及来源选择，现场目标仍未导入或切流。

## 已实现边界

- `plugin_artifacts` 明确原节点、插件编号、文件路径、大小、SHA256 和 profile。
  输入只读；普通可执行文件按 1 MiB 分块写入不可变工作空间，读取结束后重新
  校验大小及完整摘要，才发布文件描述。原权限也完整归档。
- 选择摘要绑定文件报告。源归档携带原程序全部分块，重建仅使用归档并重新核对
  每个描述、分块顺序、数量和完整哈希，不依赖原数据库或程序路径。
- 原生安装在持有离线代锁时写入 `plugins/<no>.wkp`，权限 0500；程序与配置
  一起纳入整代标识，完成全部节点后才发布 MIGRATION-COMPLETE。已发布文件
  不能被重试覆盖；本代的保留临时文件可从头续写，包括 chmod 后中断的情形。
- 独立 verify 由计划和原始归档重新推导每个目标的程序期望值；原生读适配器
  检查实际文件大小、完整 SHA256、权限、数量、缺失、额外文件和符号链接。
  它不读取导入器的文件分配结果作为正确性依据。

唯一 profile `wk-ai-example-receive-linux-amd64-v1` 固定原程序 11856443 字节，
SHA256 `671b3436d1a8d765371077009b1dfd6dec4528a1ce9cdc0dbebe2cfddc5b3224`。
要求固定 v2 源提交、每原节点只有一个 wk.plugin.ai-example 注册、版本 0.0.1、
唯一 Receive 方法、优先级 1、name-only 字符串配置、全部原程序和显式统一配置。
该单插件约束排除两版优先级／并列选择差异；不同插件绑定仍拒绝。证据绑定全部
原注册行的摘要，选择阶段仅识别这些精确原行。

没有 profile 的程序仍可捕获诊断，但会阻止 PREPARED、转换、导出和安装。
旧注册即使没有方法或有效配置，也不能授权未知程序执行。已知 profile 的程序、
版本、方法、优先级或配置超出范围时拒绝。其他消息／权威检查仍独立进行。
